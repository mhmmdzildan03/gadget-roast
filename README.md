A tiny Python program that writes one roast to /output/entry.txt: "My fitness watch applauds me for standing up, grades my sleep like a disappointed coach, then dies before I do — the only athlete in this house is its charger." Every beat is something the device actually does — stand-up applause, the morning sleep verdict, the nightly death — and the sting is saved for the charger, the one component that trains every day.

## Run it

```sh
python3 main.py
```
